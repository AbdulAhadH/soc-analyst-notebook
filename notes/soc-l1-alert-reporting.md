Why this matters
Learning about SOC alert reports, how to correctly report them and escalate them

Alert Reporting
Before the closing of an alert or the passing to L2:
Could have to communicate any investigation in detail through detailed comments, with all evidence attached especially for True Positives

How Reports help and how they can be formatted
- Detailed reports can save time by explaining what happened
- Better record keeping of all alerts
- Boosts L1 skills
- 5 W's approach could be very helpful
   - Who: The user logs in / runs the command/ downloads the file
   - What: The action that was performed
   - When: When the activity started/ended
   - Where: The device / IP/ Website involved
   - Why: Reason for the verdice


Alert Escalation
For True Positives that need more investigation escalate to L2
This is where detailed comments on the alert report will save them time

When Escalations should be made
- When more advanced tools are needed
- Alert indicates major cyberattack
- malware removal, isolation or password resets are required
- communication with the customer, management, law is needed
- When the alert is not fully understood and support is needed
